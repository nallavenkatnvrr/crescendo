# Crescendo

Offline music player for Android by **NVRR**: 10-band equalizer, 3D spatial sound, synced lyrics and visualizers. No ads, no accounts, no tracking.

This repository hosts the app's website and privacy policy (GitHub Pages):

- Website: https://nallavenkatnvrr.github.io/crescendo/
- Privacy policy: https://nallavenkatnvrr.github.io/crescendo/privacy.html
